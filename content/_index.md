# 🦀 楽しく学ぶ Rust

『The Rust Programming Language』（通称 **The Book**）の重要なエッセンスを、**短く・楽しく** 学べるようにまとめたコースです。
各章は 5〜10 分で読める分量で、章末の **理解度クイズ** で手応えを確かめながら進めます。

## 進め方

1. 左のメニューの **01** から順番に読む
2. コード例は [Rust Playground](https://play.rust-lang.org/) か手元の `cargo` で実際に動かす
3. 章末のクイズに挑戦！ 選ぶとすぐに正誤と解説が表示されます
4. 全問正解できなかったら、解説を読んで「もう一度挑戦する」

> [!NOTE] アイコンの見方
>
> - 🎯 **ゴール** — その章で身につけること
> - 💡 **ひとことで言うと** — 概念をざっくり掴む比喩
> - 🧪 **やってみよう** — 手を動かす小さな課題
> - ❌ **コンパイルエラー** — 赤枠のコードは「わざと」コンパイルが通らない例です
